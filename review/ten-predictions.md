# 2026-11-19 · 十条猜想的判读口径

单图用来回答该图怎样出错。概率命题使用同种子、同配色、同距离的组间差异。以下口径在完整网格评分前记录。表中的“支持”限定于本检查点、提示词家族、样本和干预窗口。

| 条目 | 观测或操纵 | 结论如何形成 |
|---|---|---|
| 1 高噪声平均使关系消失 | N03/N04 交换动作角色，固定噪声。在四步生成的第一、二步分别给猫侧或背景施加同强度正、负扰动，测兔侧和碗内预测速度的中心差分 | 报告时间、sigma、对端响应、角色交换对响应的影响和同面积背景对照。有跨区响应说明早期存在依赖。把它解释成语义角色编码还要满足角色对照。纯噪声端点与有少量信号的高噪声步单列 |
| 2 相似、靠近会互读，互读后更像 | 在未修改的主模型内测左至右、右至左的注意力密度、A·V 贡献以及每块前后两实体表示余弦；区域采用不重叠的躯干查询 | 检查在相同种子下，互读强度随实测距离和相似度的变化，以及之后表示是否更接近。相关读数与 N04 的定向干预分别报告。“注意力是唯一来源”需要排除其他计算通路，分量替换不能独自回答唯一性 |
| 3 需要互斥时反而趋同 | N02 的佩戴者/衔端者，N04 的碗底/碗沿执行者 | 各自记录角色复制、角色交换或动作缺失。一项属性被双方复制属于趋同，完整角色对调仍保留差异，不能合并解释 |
| 4 内容主导特征错，距离影响小 | 衣色的 3 档相似度 × 4 档距离 × 2 种画法，固定配色/种子。围巾和碗是持物、动作的另两个任务 | 分开统计 swap 与 converge，再比较相似度效应与距离效应。尝试 5、10、15 个百分点的实用等效范围，并报告所用范围；仅凭不显著不能宣称与距离无关。衣色结果按衣色表述 |
| 5 相似且靠近会融合成一人 | 各格同时记录 undercount、overcount、实际遮挡、合并的身体轮廓 | 逐图区分检测漏报、画面遮挡、真少画、可见混合形态。比较高相似近距的真少画率与其他格。底图已经多画、最终保留三人的样本单列 |

| 7 草图只能定位置 | 同一固定布局，两轮廓交换身份（带柄杯/高脚杯），文字提示逐字相同，另设只有两位置框的草图。固定种子 0–7 | 检查同种子下交换轮廓是否翻转两侧输出身份。该操纵分别检验有身份轮廓的草图与纯位置框 |
| 8 后画同类会照抄，重复扩散会退化 | 800 次主实验测新增对象 copy 和原主体 drift。补充 16 张底图，三轮递归编辑，对照每轮重新使用原图并配同一轮噪声 | 分开报告照抄率、旧错误继承率、正确转错和错转正确。以对象数量、衣色、可见身体完整性衡量保持度。风格变动和像素差距不直接当成质量下降 |

| 10 整体可观测预测 | 同时给出各格特征趋同、对调、少画、多画、copy 和 drift；逐格保留分子分母；报告配对效应 | 清楚列出在哪些任务和画法上趋势支持、在哪些方向相反、哪些可见限制来自检测或条件依赖。单例、筛选得到的错误集和全量错误率分别解释 |

## 第 1 条的数学边界

设干净的两处取值只能是 (+1,−1) 或 (−1,+1)，两个组合等概率。加独立高斯噪声后观测 X = αY + σε。则 E[Y | X] = (m,−m)，m = tanh(α(X左−X右)/σ²)。两处无条件均值都为零，但只要 α 非零，另一处的观测会改变本处的条件均值。在完全独立的纯噪声端点 α=0，这个例子的条件均值确实为零。FLUX 跳过或专门编码了哪类关系属于实测问题。流匹配的边缘场在理论上是按当前状态加权的条件速度场平均。[原始论文](https://arxiv.org/abs/2210.02747)
